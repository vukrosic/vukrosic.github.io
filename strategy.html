What to work on right now

Help us find faster database algorithms.

Open Discovery uses AI agents to improve commercially useful algorithms. We are starting with databases. Logistics comes later, after we prove the process and find a real design partner.

The first job is not optimization. The first job is to set up a fair evaluation that can tell us whether a change is correct, genuinely faster, and commercially useful.

  1. Choose one database task.

    Pick one expensive operation with open code, realistic inputs, and measurable value.

    JOINS · GROUPED AGGREGATION · SORTING · TOP-N · SCANS · FILTERS · QUERY PLANNING · INDEXES · COMPRESSION · SPILLING

  2. Let the lead AI agent set up the environment.

    Give it the repository and objective. It can inspect the code, install dependencies, build the project, find the relevant tests and benchmarks, and supervise other agents.

  3. Make the evaluation fair before searching.

    Freeze the source version, untouched baseline, machine, build flags, correctness tests, representative workloads, timing method, memory checks, and success rule. Keep some cases held out for final confirmation.

  4. Search many isolated ideas.

    The lead agent can orchestrate other agents to try different algorithmic mechanisms. Each attempt must have its own files and must never modify the baseline or evaluator.

  5. Confirm only real wins.

    Check identical outputs first. Then compare repeated baseline-versus-candidate runs under low contention. Rebuild the winner cleanly and test it on held-out workloads. Preserve failures and slower results too.

  6. Connect the result to customer value.

    Explain whether the improvement reduces latency, cloud cost, memory, or machines required. After repeatable database wins, use the same evidence-first process for routing, dispatch, matching, and scheduling in logistics.

Instruction for the lead agent

Own the full loop. Set up the environment, establish a fair frozen evaluation, coordinate isolated search agents, protect the baseline and evaluator, manage machine contention, test correctness before speed, independently confirm winners, and report only what the evidence supports.
