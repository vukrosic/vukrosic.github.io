Find faster algorithms

We will use an AI agent to find and verify faster algorithms. We are starting with databases because database performance is commercially valuable and easier to measure and sell. Once this works repeatedly, we can expand into logistics.

Copy-paste prompt
Find a faster commercially useful database algorithm in this repository. Own the entire process: set up the environment, choose a valuable bottleneck, and establish a fair evaluation before changing code. Freeze the baseline, correctness tests, representative benchmarks, held-out cases, build settings, and success rule. Then test isolated improvements and coordinate other agents if useful. Protect the baseline and evaluator, avoid benchmark contention, preserve all results, and independently rerun any winner from a clean build. Report only reproducible speedups with matching outputs.
